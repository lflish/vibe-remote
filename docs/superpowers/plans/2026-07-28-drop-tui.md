# 删除 TUI 字节透传线 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 彻底删除 TUI 字节透传线（PTY→tmux→claude + xterm）——服务端 `runner.go`/`wsRelay`/`wsOpenTUI`/tmux reconcile/sessions REST + 客户端 `resize`/`sessions`/`listSessions`/`renameSession` 及桌面/移动端旧侧边栏——保留 headless 结构化线为唯一数据平面。约 1300+ 行删除（1000+ Go + 300+ TS）+ 桌面/移动端侧边栏改为 workdir 列表（对齐 web 方案 A）。

**Architecture:** 客户端**已经**全部走 `mode:'headless'`，TUI 线在服务端存活但无客户端入口。此计划把它整块拆除，同时把 desktop/mobile 的 sessions-based 侧边栏改为 workdir-based（复用 web 已建立的方案 A：workdir 列表存本地，会话身份即 workdir）。删除是不可逆决策——失去跑 vim/htop/claude 原生 TUI 的能力（用户明确接受：登录机器有终端）。

**Tech Stack:** Go 1.22（服务端），TypeScript + React 19（三端），npm workspaces monorepo。

## Global Constraints

- **协议单一事实来源**：`packages/core/src/protocol.ts`（TS）与 `vibe-remoted/internal/protocol/protocol.go`（Go）手工镜像，改协议时**两端 + `docs/protocol.md`** 都要改。
- **不动 headless 线**：`session/headless.go`、`ws.go` 的 `wsHeadless`、`session/history.go`、`/api/v1/history` REST、`packages/core/src/chat/**`、`packages/ui/**` 保持不变。
- **不动客户端结构化视图**：`mountChat`、`ChatPane`、`ChatView` 逻辑不变；只改机器/侧边栏外壳。
- **会话 = workdir 模型**（web 已实现，desktop/mobile 迁移到同款）：workdir 列表存本地（Electron userData / Capacitor Preferences / localStorage），侧边栏列 workdir 而不是 tmux 会话。
- **保留 events 环境注入**：`VIBE_REMOTE_SESSION_ID`/`VIBE_REMOTE_EVENTS_URL`/`VIBE_REMOTE_TOKEN` 环境变量注入 headless claude 的路径**保留**（供未来钩子），但 pub/sub 通道（Subscribe/PublishEvent/notify 帧/`POST /api/v1/events`）删除——它只服务 tmux sessions map。**修正**：如果 headless.go 没有 sessionID 概念（会话=workdir），events 端点删了 headless 也用不上；一并删。
- 每个 Task 独立可 build + typecheck + test 绿；不留死引用。
- 分支 `feature/drop-tui`（已建）。BASE = `ebae76f`（当前 main HEAD）。

新 rest.ts 完整代码：
```ts
import type { MachineConfig } from './protocol';

/**
 * REST client for a vibe-remoted instance.
 */
export class VibeRemoteRest {
  constructor(private machine: MachineConfig) {}

  private base(): string {
    return `http://${this.machine.addr}:${this.machine.port}`;
  }

  private headers(): HeadersInit {
    return { Authorization: `Bearer ${this.machine.token}` };
  }

  async info(): Promise<MachineInfo> {
    const res = await fetch(`${this.base()}/api/v1/info`, { headers: this.headers() });
    if (!res.ok) throw new Error(`info failed: ${res.status}`);
    return res.json();
  }

  /** List directory entries (directories only) for the remote picker. */
  async listDir(path?: string): Promise<DirListing> {
    const url = new URL(`${this.base()}/api/v1/fs`);
    if (path) url.searchParams.set('path', path);
    const res = await fetch(url.toString(), { headers: this.headers() });
    if (!res.ok) throw new Error(`fs failed: ${res.status}`);
    return res.json();
  }

  /** Fetch recent conversation turns for a workdir (for history backfill). */
  async history(workdir: string, limit = 50): Promise<HistoryTurn[]> {
    const url = new URL(`${this.base()}/api/v1/history`);
    url.searchParams.set('path', workdir);
    url.searchParams.set('limit', String(limit));
    const res = await fetch(url.toString(), { headers: this.headers() });
    if (!res.ok) throw new Error(`history failed: ${res.status}`);
    const data = await res.json();
    return data.turns || [];
  }
}

export interface ClaudeFlagInfo {
  id: string;
  label: string;
  default?: boolean;
}

export interface MachineInfo {
  hostname: string;
  tmux_enabled: boolean;
  default_workdir: string;
  allowed_roots: string[];
  claude_flags?: ClaudeFlagInfo[];
}

export interface DirEntry {
  name: string;
  path: string;
}

export interface DirListing {
  path: string;
  entries: DirEntry[];
}

export interface HistoryTurn {
  role: 'user' | 'assistant';
  text: string;
}
```

- [ ] **Step 2: 加 IPC handler —— `desktop/src/main/index.ts`**

主进程侧存到 userData 下的 `workdirs.json`：
```ts
import { ipcMain, app } from 'electron';
import * as fs from 'fs';
import * as path from 'path';

const workdirsFile = path.join(app.getPath('userData'), 'workdirs.json');

// key: machineKey → dirs[]
function readAll(): Record<string, string[]> {
  try { return JSON.parse(fs.readFileSync(workdirsFile, 'utf8')); } catch { return {}; }
}
function writeAll(m: Record<string, string[]>) {
  fs.writeFileSync(workdirsFile, JSON.stringify(m, null, 2));
}

ipcMain.handle('workdirs:get', (_e, machineKey: string) => readAll()[machineKey] ?? []);
ipcMain.handle('workdirs:add', (_e, args: { machineKey: string; dir: string }) => {
  const all = readAll();
  const cur = all[args.machineKey] ?? [];
  if (!cur.includes(args.dir)) all[args.machineKey] = [...cur, args.dir];
  writeAll(all);
});
```

- [ ] **Step 1: 扩展 `mobile/src/storage.ts`**

在 `makeMachineStore` 返回对象里加两个方法：
```ts
export function makeMachineStore(kv: KV) {
  return {
    async getMachines(): Promise<MachineConfig[]> { /* 原实现 */ },
    async saveMachines(machines: MachineConfig[]): Promise<void> { /* 原实现 */ },
    async getWorkdirs(machineKey: string): Promise<string[]> {
      const raw = await kv.get(`vibe-remote.workdirs.${machineKey}`);
      if (!raw) return [];
      try {
        const parsed = JSON.parse(raw);
        return Array.isArray(parsed) ? (parsed as string[]) : [];
      } catch {
        return [];
      }
    },
    async addWorkdir(machineKey: string, dir: string): Promise<void> {
      const cur = await this.getWorkdirs(machineKey);
      if (cur.includes(dir)) return;
      await kv.set(`vibe-remote.workdirs.${machineKey}`, JSON.stringify([...cur, dir]));
    },
  };
}
```

## 附录 A: 新版 client.ts

新 client.ts 完整代码（Task 1 Step 2 照抄）：

```ts
import {
  FrameType,
  type AuthFrame,
  type AttachFrame,
  type DataFrameC2S,
  type PingFrame,
  type ServerFrame,
  type MachineConfig,
} from './protocol';

export enum ConnectionState {
  Disconnected = 'disconnected',
  Connecting = 'connecting',
  Connected = 'connected',
  Reconnecting = 'reconnecting',
  Error = 'error',
}

const RECONNECT_BASE_DELAY = 1000;
const RECONNECT_MAX_DELAY = 30000;
const PING_INTERVAL = 25000;

/**
 * VibeRemoteClient — WS 客户端。auth + attach(headless) + data relay + ping/pong + 自动重连。
 * TUI 线（resize/sessions/mode）已删除；attach 只需 workdir + flags。
 */
export class VibeRemoteClient {
  machine: MachineConfig;
  state: ConnectionState = ConnectionState.Disconnected;

  onStateChange?: (state: ConnectionState, attempt: number) => void;
  onData?: (payload: string) => void;
  onExit?: (code: number) => void;
  onError?: (message: string) => void;
  onReady?: (workdir: string) => void;

  private ws: WebSocket | null = null;
  private reconnectAttempt = 0;
  private reconnectTimer: ReturnType<typeof setTimeout> | null = null;
  private pingTimer: ReturnType<typeof setInterval> | null = null;
  private pendingAttach: { workdir?: string; flags?: string[] } | null = null;
  private lastAttach: { workdir?: string; flags?: string[] } | null = null;

  constructor(machine: MachineConfig) {
    this.machine = machine;
  }

  connect() {
    if (this.ws) this.ws.close();
    this.setState(ConnectionState.Connecting);
    const url = `ws://${this.machine.addr}:${this.machine.port}/ws`;
    this.ws = new WebSocket(url);

    this.ws.onopen = () => {
      this.send<AuthFrame>({ type: FrameType.Auth, token: this.machine.token });
      this.setState(ConnectionState.Connected);
      this.startPing();
      if (this.pendingAttach) {
        this.send<AttachFrame>({
          type: FrameType.Attach,
          workdir: this.pendingAttach.workdir,
          flags: this.pendingAttach.flags,
        });
        this.pendingAttach = null;
      }
    };
    this.ws.onmessage = (event) => this.handleMessage(event.data as string);
    this.ws.onclose = () => {
      this.stopPing();
      if (this.state !== ConnectionState.Disconnected) {
        this.setState(ConnectionState.Reconnecting);
        this.scheduleReconnect();
      }
    };
    this.ws.onerror = () => this.setState(ConnectionState.Error);
  }

  disconnect() {
    this.setState(ConnectionState.Disconnected);
    this.stopPing();
    if (this.reconnectTimer) { clearTimeout(this.reconnectTimer); this.reconnectTimer = null; }
    if (this.ws) { this.ws.close(); this.ws = null; }
  }

  reconnectNow() {
    if (this.reconnectTimer) { clearTimeout(this.reconnectTimer); this.reconnectTimer = null; }
    if (this.lastAttach) this.pendingAttach = { ...this.lastAttach };
    this.connect();
  }

  /** Attach headless — 会话 = workdir。workdir 空表示服务端默认目录。 */
  attach(workdir?: string, flags?: string[]) {
    this.lastAttach = { workdir, flags };
    if (this.state === ConnectionState.Connected && this.ws) {
      this.send<AttachFrame>({ type: FrameType.Attach, workdir, flags });
    } else {
      this.pendingAttach = { workdir, flags };
    }
  }

  sendData(base64Payload: string) {
    this.send<DataFrameC2S>({ type: FrameType.Data, payload: base64Payload });
  }

  private handleMessage(raw: string) {
    let frame: ServerFrame;
    try { frame = JSON.parse(raw); } catch { return; }
    switch (frame.type) {
      case FrameType.Ready:
        this.reconnectAttempt = 0;
        this.onReady?.(frame.workdir);
        break;
      case FrameType.Data:
        this.onData?.(frame.payload);
        break;
      case FrameType.Exit:
        this.onExit?.(frame.code);
        break;
      case FrameType.Error:
        this.onError?.(frame.message);
        break;
      case FrameType.Pong:
        break;
    }
  }

  private send<T>(frame: T) {
    if (this.ws && this.ws.readyState === WebSocket.OPEN) {
      this.ws.send(JSON.stringify(frame));
    }
  }

  private setState(state: ConnectionState) {
    this.state = state;
    this.onStateChange?.(state, this.reconnectAttempt);
  }

  private scheduleReconnect() {
    const delay = Math.min(RECONNECT_BASE_DELAY * Math.pow(2, this.reconnectAttempt), RECONNECT_MAX_DELAY);
    this.reconnectAttempt++;
    this.reconnectTimer = setTimeout(() => {
      if (this.lastAttach) this.pendingAttach = { ...this.lastAttach };
      this.connect();
    }, delay);
  }

  private startPing() {
    this.pingTimer = setInterval(() => this.send<PingFrame>({ type: FrameType.Ping }), PING_INTERVAL);
  }

  private stopPing() {
    if (this.pingTimer) { clearInterval(this.pingTimer); this.pingTimer = null; }
  }
}
```
