## A2 新的校验：本地四条规则 + 不含 @{ + check-ref-format --branch 退出码为 0 且输出与输入逐字相等
name=[@{-1}]  check-ref-format --branch: exit=0 out=[prev]  => 判定 local:at_brace
name=[@{-2}]  check-ref-format --branch: exit=0 out=[main]  => 判定 local:at_brace
name=[@{u}]  check-ref-format --branch: exit=128 out=[fatal: no upstream configured for branch 'main']  => 判定 local:at_brace
name=[@]  check-ref-format --branch: exit=0 out=[@]  => 判定 OK
name=[HEAD]  check-ref-format --branch: exit=128 out=[fatal: 'HEAD' is not a valid branch name]  => 判定 git:exit=128
name=[-x]  check-ref-format --branch: exit=128 out=[fatal: '-x' is not a valid branch name]  => 判定 local:leading_dash
name=[-]  check-ref-format --branch: exit=128 out=[fatal: '-' is not a valid branch name]  => 判定 local:leading_dash
name=[a..b]  check-ref-format --branch: exit=128 out=[fatal: 'a..b' is not a valid branch name]  => 判定 local:dotdot
name=[a b]  check-ref-format --branch: exit=128 out=[fatal: 'a b' is not a valid branch name]  => 判定 local:whitespace
name=[a@{b]  check-ref-format --branch: exit=128 out=[fatal: 'a@{b' is not a valid branch name]  => 判定 local:at_brace
name=[change/foo]  check-ref-format --branch: exit=0 out=[change/foo]  => 判定 OK
name=[fix-login]  check-ref-format --branch: exit=0 out=[fix-login]  => 判定 OK
name=[refs/heads/x]  check-ref-format --branch: exit=0 out=[refs/heads/x]  => 判定 OK
name=[x.lock]  check-ref-format --branch: exit=128 out=[fatal: 'x.lock' is not a valid branch name]  => 判定 git:exit=128
# 去掉「不含 @{」这条本地规则、只靠「输出与输入相等」时：
name=[@{-1}] exit=0 out=[prev] equal=no
name=[@{-2}] exit=0 out=[main] equal=no
name=[@{u}] exit=128 out=[] equal=no

######## F　tmux：创建时间能不能跟着会话走（私有 socket `tmux -L vrprobe3` + 私有 TMUX_TMPDIR，跑完 kill-server）

$ tmux -L vrprobe3 new-session -d -s vibe-remote-p1 'sleep 30'
$ tmux -L vrprobe3 set-option -t vibe-remote-p1 @vibe_remote_created '2026-11-18T14:03:07.123456789Z'
$ tmux -L vrprobe3 new-session -d -s vibe-remote-p2 'sleep 30'
$ tmux -L vrprobe3 list-sessions -F '#{session_name}|#{@vibe_remote_created}|#{session_created}'
vibe-remote-p1|2026-11-18T14:03:07.123456789Z|1794988721
vibe-remote-p2||1794988721
$ date +%s
1794988721
$ tmux -L vrprobe3 respawn-pane -k -t vibe-remote-p1 'sleep 30'; sleep 1.2      # 相当于「重载」
$ tmux -L vrprobe3 list-sessions -F '#{session_name}|#{@vibe_remote_created}|#{session_created}' | head -1
vibe-remote-p1|2026-11-18T14:03:07.123456789Z|1794988721
# 用户选项原样读回；没写过的是空串；tmux 自带的 #{session_created}（unix 秒）在 respawn-pane 之后不变。
