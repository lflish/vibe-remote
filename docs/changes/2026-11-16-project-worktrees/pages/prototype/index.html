推荐 M1：最接近你给的参考图；项目、worktree、会话三层靠标题样式区分，不靠层层缩进，层次最清楚。同时开的会话很多、想一屏看全，选 M2；不想丢掉现在的暖色，选 M3。按数字键 1 / 2 / 3 可以在同一个画面上来回切换。

1对话会话（主画面）

侧边栏：机器 → 项目 → worktree → 会话。只有一个 worktree 的项目不显示 worktree 层；折叠的项目把「等你处理」的点显示在项目行上。点项目行可以折叠。状态点：空心灰 = 有新消息，实心绿 = 回合结束，带光圈的黄 = 等你处理。

实际界面里，权限卡片出现时会替换输入框（现有行为不变）；这里为了一张图看全，把两者都画了出来。当前打开的会话不显示状态点（现有行为）。

2终端会话

只换外壳：侧边栏、标题、状态栏，以及终端的底色、前景色、光标和选区颜色跟随方案。终端里的文字、框线和颜色是远程输出的原样，三个方案下完全相同。

3新建 worktree

从 devflow 的 main 发起。名字就是新分支名，基于发起处当前的提交。

4在已有 worktree 里新建会话

目录固定为这个 worktree，所以只选界面和启动选项，没有目录列表和会话模式。

5删除 worktree 和删除会话

删除 worktree 按会不会丢东西分三种确认；删除会话不再顺带删除 worktree 和分支。

6连着旧版 daemon 的机器

新桌面端连上还没升级的 vibe-remoted：照常工作，只是少了需要新接口的入口。

选好后在终端回复 M1，或 M2 + M1 的气泡 这样组合。
