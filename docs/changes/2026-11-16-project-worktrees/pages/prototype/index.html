1对话会话（主画面）

对应 R1.1–R1.3、R1.6、R1.7、R7、R8.1。侧边栏：机器 → 项目 → worktree → 会话。只有一个 worktree 的项目（new-api）和不在 git 里的目录（notes）不显示 worktree 层；折叠的项目（vibeview）把「等你处理」的点显示在项目行上。顶部标题是「项目 / 分支 / 会话名」。状态点：空心灰 = 有新消息，实心绿 = 回合结束，带光圈的黄 = 等你处理。点项目行可以折叠。

快捷键（R7，界面上不显示序号）：⌘1–⌘9 打开侧边栏从上到下的第 1–9 个可见会话，图里「重排 skill 目录」是 ⌘1、「登录修复」是 ⌘3、「周报整理」是 ⌘6；⌘⇧[ / ⌘⇧] 切到上一个 / 下一个，到头循环。折叠的项目（vibeview）里的会话会被跳过；有对话框开着时不切换；焦点在终端或输入框里也照常切换。

实际界面里，权限卡片出现时会替换输入框（现有行为不变）；这里为了一张图看全，把两者都画了出来。当前打开的会话不显示状态点（现有行为）。

2终端会话

对应 R8.2、R1.7。只换外壳：侧边栏、标题、状态栏，以及终端的底色、前景色、光标和选区颜色。终端里的文字、框线和颜色是远程输出的原样显示，客户端不解析。

4新建 worktree

对应 R3.1–R3.6、R3.10。从 devflow 的 main 发起。名字就是新分支名，基于发起处当前的提交；名字里的斜杠在目录名里换成连字符（change/foo → 目录 change-foo）。出错时原因显示在名字下方，不创建任何东西。

5在已有 worktree 里新建会话

对应 R4.1、R4.4、R6.1。目录固定为这个 worktree，所以只选界面和启动选项，没有目录列表和会话模式。

6删除 worktree 和删除会话的确认

对应 R5.1–R5.6、R5.8、R5.11。删除 worktree 按会不会丢东西分情形确认，(d)(e)(f) 和 (a) 里被忽略文件的那一句是新增的；几种情形同时成立时，各自的那一段都会显示。删除会话不再顺带删除 worktree 和分支。

7删除 worktree 失败时的提示新增

对应 R5.9 和 R5.6。失败时回到同一个确认框，原因显示在最上面。分两种：还没动手就发现删不了（什么都没变），和已经结束会话或开始删除之后才失败（如实写出现在剩下什么）。

8连着旧版 daemon 的机器

对应 R9.1。新桌面端连上还没升级的 vibe-remoted：照常工作，只是少了需要新接口的入口。

这是选定的 M1 方案。有想调整的地方，在终端里直接说，例如：会话行再紧凑一点、气泡颜色淡一点。
